# Manual de Usuario - El Correo de Yury

## Introducción
"El Correo de Yury" es una aplicación para la gestión de recursos humanos, trabajadores, cargas familiares y contactos de emergencia.

## Primeros Pasos
1. Inicie la aplicación ejecutando `python main.py`.
2. Inicie sesión con su usuario y contraseña.

## Módulo de Login
- Ingrese su usuario y contraseña para acceder.
- Si no tiene cuenta, use el botón "Registrar".

## Vista de RRHH
- Añadir Trabajador: Botón para agregar un nuevo trabajador.
- Filtrar: Permite filtrar trabajadores por sexo, cargo, área o departamento.
- Eliminar: Seleccione un trabajador y pulse "Eliminar".
- Cargas Familiares y Contactos: Desde la ficha del trabajador puede gestionar estos datos.

## Vista de Trabajador
- Modificar mis Datos: Permite actualizar sus datos personales.
- Ver cargas familiares y contactos de emergencia.

## Preguntas Frecuentes
- ¿Qué hago si olvido mi contraseña? Contacte a RRHH.
- ¿Puedo modificar mi RUT? No, el RUT es único y no editable.
